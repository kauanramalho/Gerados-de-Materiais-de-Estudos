# Amostra editorial e de navegação

Pequeno exemplo original sobre switch, usando a ideia citada pelo titular. Demonstra teoria, figura com portas identificadas, exemplo resolvido, duas questões autorais e links para resoluções com retorno.

Não é um capítulo completo de concurso nem análise de banca. Nenhuma questão real foi coletada para esta amostra. As referências técnicas estão no material; as decisões editoriais são propostas do projeto.

Gerar pela raiz: `python scripts/build_sample.py --pdf`. Abrir `build/amostra.html` ou `build/amostra.pdf`. A figura é um esquema genérico original, sem atribuição a equipamento comercial; não representa console, PoE, velocidade ou configuração de modelo específico.
