# Piloto Dataprev — modelagem relacional e SQL

Material original para validar o fluxo editorial do Ateliê de Estudos, com referência pública ao edital Dataprev/FGV 2026, Desenvolvimento de Software. Não expressa prioridade pessoal do titular nem cobre todo o edital.

O capítulo contém três unidades teóricas, três esquemas, exemplos executáveis, oito questões autorais e três referências a questões reais. Os itens reais são acessados na prova oficial; os comentários são originais. O gabarito de 2026 consultado é preliminar.

```sh
python scripts/build_material.py materials/dataprev-sql/material.json --check
python scripts/check_sql.py materials/dataprev-sql/verificacoes.json
python scripts/build_material.py materials/dataprev-sql/material.json --pdf
python scripts/build_material.py materials/dataprev-sql/material.json --kind caderno --pdf
```

Saídas: build/dataprev-sql/apostila.pdf e caderno.pdf, HTMLs, mapas de sumário e relatórios de integridade. A autoria por IA e a revisão inicial não equivalem a aceite pedagógico pelo leitor.
